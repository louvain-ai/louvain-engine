# retriever-figures

For a search that asks for a figure (`how much`, `total`, `budget`, a currency sign), the passages that state one,
by meaning and by words, at half the depth of a leg, as the leg `figures`. Any other search reads
nothing here. A read that fails is reported as `passages:digits` and costs this leg only.

It takes no settings. The engine runs it by default, after the passages retriever.
